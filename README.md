# Srifix Studios — Sections

Four homepage sections from the Srifix Studios website, as a standalone React + Vite project:

1. **Features** — services showcase around an interactive 3D logo
2. **How We Work** — pull-cord desk lamp that lights up the four process steps
3. **Why Us** — honeycomb stats with count-up numbers
4. **Client Review** — testimonials flying out of a canyon portal

## Run

```bash
npm install
npm run dev
```

Built with React, GSAP (ScrollTrigger), Lenis, three.js / react-three-fiber.
